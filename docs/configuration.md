# Configuration Reference

After publishing via `php artisan vendor:publish --tag=google-drive-backup-config`, you can configure the package in `config/google-drive-backup.php` or directly through `.env` variables.

---

## Environment Variables & Use Cases

### 1. General & Environment Identifiers

| Config Key | Environment Variable | Default | Use Case & Description |
|---|---|---|---|
| `enabled` | `GOOGLE_DRIVE_BACKUP_ENABLED` | `true` | **Disable in staging/local:** Set to `false` in development, testing, or CI environments to prevent unintentional backups. |
| `application_name` | `GOOGLE_DRIVE_BACKUP_APP_NAME` | `env('APP_NAME', 'laravel')` | **Multi-app identification:** Used in backup filenames and folder naming. Set this if your app name contains spaces or special characters. |
| `environment` | `GOOGLE_DRIVE_BACKUP_ENV` | `env('APP_ENV', 'production')` | **Environment namespace:** Tag backup archives as `production`, `staging`, etc. |

### 2. Database Connection & Default Backup Type

| Config Key | Environment Variable | Default | Use Case & Description |
|---|---|---|---|
| `database_connection` | `GOOGLE_DRIVE_BACKUP_DB_CONNECTION` | `env('DB_CONNECTION')` | **Target database:** Explicitly specify the database driver to dump (`mysql`, `mariadb`, `pgsql`, `sqlite`, `sqlsrv`). |
| `default_type` | `GOOGLE_DRIVE_BACKUP_TYPE` | `database` | **Default backup scope:** Default action when no flag (`--db`, `--files`, `--full`) is passed. Options: `database`, `files`, `full`. |

### 3. Google Drive Storage & Subfolders

| Config Key | Environment Variable | Default | Use Case & Description |
|---|---|---|---|
| `subfolders` | `GOOGLE_DRIVE_BACKUP_SUBFOLDERS` | `false` | **Environment separation:** When `true`, nests backups into an environment folder (e.g. `production/`). Default `false` stores directly in the root folder. |
| `subfolder_by_type` | `GOOGLE_DRIVE_BACKUP_SUBFOLDER_BY_TYPE` | `false` | **Automatic type sorting:** When `true`, automatically puts backups into `database/`, `files/`, or `full/` subfolders on Google Drive. |
| `google.client_id` | `GOOGLE_DRIVE_CLIENT_ID` | `null` | Google Cloud OAuth 2.0 Web Client ID. |
| `google.client_secret` | `GOOGLE_DRIVE_CLIENT_SECRET` | `null` | Google Cloud OAuth 2.0 Client Secret. |
| `google.refresh_token` | `GOOGLE_DRIVE_REFRESH_TOKEN` | `null` | Long-lived OAuth refresh token generated by `php artisan backup:google-drive:refresh-token`. |
| `google.folder_id` | `GOOGLE_DRIVE_BACKUP_FOLDER_ID` | `null` | Target Google Drive folder ID from the URL. Leave blank to auto-create. |
| `google.folder_name` | `GOOGLE_DRIVE_BACKUP_FOLDER_NAME` | `Laravel Backups` | Folder name to create on Google Drive if `folder_id` is not specified. |
| `google.shared_drive_id` | `GOOGLE_DRIVE_SHARED_DRIVE_ID` | `null` | **Team / Shared Drive:** Specify when backing up to an enterprise Google Shared Drive. |

### 4. Filename Format

| Config Key | Environment Variable | Default | Use Case & Description |
|---|---|---|---|
| `filename.format` | `GOOGLE_DRIVE_BACKUP_FILENAME_FORMAT` | `{app}-{env}-{type}-{date}-{time}-{uuid}.zip` | Custom filename pattern using tokens: `{app}`, `{env}`, `{type}`, `{date}`, `{time}`, `{uuid}`. |

### 5. Backup Scope & Compression

| Config Key | Environment Variable | Default | Use Case & Description |
|---|---|---|---|
| `backup.database` | `GOOGLE_DRIVE_BACKUP_INCLUDE_DATABASE` | `true` | Include database dump during full backups. |
| `backup.files` | `GOOGLE_DRIVE_BACKUP_INCLUDE_FILES` | `true` | Include application files during full backups. |
| `compression.enabled` | `GOOGLE_DRIVE_BACKUP_COMPRESSION_ENABLED` | `true` | Compress backup archives using ZIP. |
| `compression.format` | `GOOGLE_DRIVE_BACKUP_COMPRESSION_FORMAT` | `zip` | Archive compression format. |

### 6. Encryption & Security

| Config Key | Environment Variable | Default | Use Case & Description |
|---|---|---|---|
| `encryption.enabled` | `GOOGLE_DRIVE_BACKUP_ENCRYPTION_ENABLED` | `false` | **Zero-knowledge encryption:** Encrypt archive before upload for compliance (GDPR, HIPAA, SOC-2). |
| `encryption.cipher` | `GOOGLE_DRIVE_BACKUP_ENCRYPTION_CIPHER` | `aes-256-cbc` | Encryption cipher standard. |
| `encryption.key` | `GOOGLE_DRIVE_BACKUP_ENCRYPTION_KEY` | `null` | 32-character encryption key (never commit to version control). |

### 7. Post-Upload Verification

| Config Key | Environment Variable | Default | Use Case & Description |
|---|---|---|---|
| `verification.enabled` | `GOOGLE_DRIVE_BACKUP_VERIFY_ENABLED` | `true` | Verify file immediately after upload to Google Drive. |
| `verification.mode` | `GOOGLE_DRIVE_BACKUP_VERIFY_MODE` | `metadata` | Verification mode: `none`, `metadata` (fast), `checksum` (MD5 check), or `full-download` (byte-for-byte check). |
| `verification.checksum` | `GOOGLE_DRIVE_BACKUP_VERIFY_CHECKSUM` | `sha256` | Checksum algorithm. |

### 8. Retention Policy Rules

Evaluated automatically by `php artisan backup:google-drive:clean` (no parameters needed). Backups are grouped by type so database backups and file backups never compete.

| Config Key | Environment Variable | Default | Use Case & Description |
|---|---|---|---|
| `retention.daily` | `GOOGLE_DRIVE_BACKUP_RETENTION_DAILY` | `30` | **Daily retention:** Keeps 1 backup per calendar day for up to 30 days. Also keeps **all intra-day backups** (e.g. every 4 hours) for the most recent day. |
| `retention.weekly` | `GOOGLE_DRIVE_BACKUP_RETENTION_WEEKLY` | `8` | **Weekly retention:** Keeps 1 backup per ISO week for up to 8 distinct weeks. |
| `retention.monthly` | `GOOGLE_DRIVE_BACKUP_RETENTION_MONTHLY` | `12` | **Monthly retention:** Keeps 1 backup per calendar month for up to 12 distinct months. |

### 9. Logging

| Config Key | Environment Variable | Default | Use Case & Description |
|---|---|---|---|
| `logging.enabled` | `GOOGLE_DRIVE_BACKUP_LOG_ENABLED` | `true` | Record backup, upload, and pruning operations. |
| `logging.channel` | `GOOGLE_DRIVE_BACKUP_LOG_CHANNEL` | `stack` | Destination log channel (e.g. `single`, `daily`, `slack`). Sensitive tokens are always redacted. |

---

## Full `.env` Example

```env
# ── Google OAuth 2.0 Credentials (Required) ─────────────────────────
GOOGLE_DRIVE_CLIENT_ID=your-client-id.apps.googleusercontent.com
GOOGLE_DRIVE_CLIENT_SECRET=your-client-secret
GOOGLE_DRIVE_REFRESH_TOKEN=your-refresh-token

# ── Google Drive Destination (Optional) ──────────────────────────────
GOOGLE_DRIVE_BACKUP_FOLDER_ID=
GOOGLE_DRIVE_BACKUP_FOLDER_NAME="Laravel Backups"
GOOGLE_DRIVE_SHARED_DRIVE_ID=

# ── Database & Default Backup Scope (Optional) ───────────────────────
GOOGLE_DRIVE_BACKUP_DB_CONNECTION=mysql
GOOGLE_DRIVE_BACKUP_TYPE=database

# ── Subfolder Organization (Optional) ───────────────────────────────
GOOGLE_DRIVE_BACKUP_SUBFOLDERS=false
GOOGLE_DRIVE_BACKUP_SUBFOLDER_BY_TYPE=false

# ── Retention Policy Rules (Optional) ───────────────────────────────
GOOGLE_DRIVE_BACKUP_RETENTION_DAILY=30
GOOGLE_DRIVE_BACKUP_RETENTION_WEEKLY=8
GOOGLE_DRIVE_BACKUP_RETENTION_MONTHLY=12

# ── Encryption (Optional) ───────────────────────────────────────────
GOOGLE_DRIVE_BACKUP_ENCRYPTION_ENABLED=false
GOOGLE_DRIVE_BACKUP_ENCRYPTION_KEY=

# ── Verification & Logging (Optional) ───────────────────────────────
GOOGLE_DRIVE_BACKUP_VERIFY_MODE=metadata
GOOGLE_DRIVE_BACKUP_ENABLED=true
GOOGLE_DRIVE_BACKUP_LOG_CHANNEL=stack
```
