# Configuration Reference

After publishing via `php artisan vendor:publish --tag=google-drive-backup-config`, you can configure the package in `config/google-drive-backup.php` or directly through `.env` variables.

---

## Environment Variables & Use Cases

### 1. General & Environment Identifiers

| Config Key | Environment Variable | Default | Use Case & Description |
|---|---|---|---|
| `enabled` | `GOOGLE_DRIVE_BACKUP_ENABLED` | `true` | **Disable in staging/local:** Set to `false` in development, testing, or CI environments to prevent unintentional backups. |
| `application_name` | `GOOGLE_DRIVE_BACKUP_APP_NAME` | `env('APP_NAME', 'laravel')` | **Multi-app identification:** Used in backup filenames and folder naming. Set this if your app name contains spaces or special characters. |
| `environment` | `GOOGLE_DRIVE_BACKUP_ENV` | `env('APP_ENV', 'production')` | **Environment namespace:** Tag backup archives as `production`, `staging`, etc. |

### 2. Database Connection

The package uses your standard Laravel database configuration without needing custom backup environment variables.

| Config Key | Environment Variable | Default | Use Case & Description |
|---|---|---|---|
| `database_connection` | `DB_CONNECTION` | `config('database.default')` | Automatically uses standard Laravel `DB_CONNECTION`. Can be overridden dynamically on the command line via `--connection=<name>`. |

### 3. Google Drive Credentials & Root Folder

By default, all backups are uploaded directly to the root folder specified below. If you want to upload to a specific subfolder on Google Drive, pass `--subfolder=<name>` in your command.

| Config Key | Environment Variable | Default | Use Case & Description |
|---|---|---|---|
| `google.client_id` | `GOOGLE_DRIVE_CLIENT_ID` | `null` | Google Cloud OAuth 2.0 Web Client ID. |
| `google.client_secret` | `GOOGLE_DRIVE_CLIENT_SECRET` | `null` | Google Cloud OAuth 2.0 Client Secret. |
| `google.refresh_token` | `GOOGLE_DRIVE_REFRESH_TOKEN` | `null` | Long-lived OAuth refresh token generated by `php artisan backup:google-drive:refresh-token`. |
| `google.folder_id` | `GOOGLE_DRIVE_BACKUP_FOLDER_ID` | `null` | Target Google Drive folder ID from the URL. Leave blank to auto-create or find existing. |
| `google.folder_name` | `GOOGLE_DRIVE_BACKUP_FOLDER_NAME` | `Laravel Backups` | Folder name to search or create on Google Drive if `folder_id` is not specified. |

### 4. Filename Format

| Config Key | Environment Variable | Default | Use Case & Description |
|---|---|---|---|
| `filename.format` | `GOOGLE_DRIVE_BACKUP_FILENAME_FORMAT` | `{app}-{env}-{type}-{date}-{time}-{uuid}.zip` | Custom filename pattern using tokens: `{app}`, `{env}`, `{type}`, `{date}`, `{time}`, `{uuid}`. |

### 5. Backup Scope & Dynamic Paths

By default, the package archives database dumps and application files into standard ZIP archives.

> **Tip:** You can target specific files or folders (such as uploaded images or user documents) dynamically at runtime using the `--path` CLI option:
> ```bash
> php artisan backup:google-drive --files --path="storage/app/public/images" --subfolder=images
> ```

### 6. Post-Upload Verification

| Config Key | Environment Variable | Default | Use Case & Description |
|---|---|---|---|
| `verification.mode` | `GOOGLE_DRIVE_BACKUP_VERIFY_MODE` | `metadata` | Verification mode: `none`, `metadata` (fast existence & size check), `checksum` (MD5 check), or `full-download` (byte-for-byte check). |

### 7. Retention Policy Rules

Evaluated automatically by `php artisan backup:google-drive:clean` (no parameters needed). Backups are grouped by type so frequent database backups never delete file backups.

| Config Key | Environment Variable | Default | Use Case & Description |
|---|---|---|---|
| `retention.daily` | `GOOGLE_DRIVE_BACKUP_RETENTION_DAILY` | `30` | **Daily retention:** Keeps 1 backup per calendar day for up to 30 days. Also keeps **all intra-day backups** (e.g. every 4 hours) for the most recent day. |
| `retention.weekly` | `GOOGLE_DRIVE_BACKUP_RETENTION_WEEKLY` | `8` | **Weekly retention:** Keeps 1 backup per ISO week for up to 8 distinct weeks. |
| `retention.monthly` | `GOOGLE_DRIVE_BACKUP_RETENTION_MONTHLY` | `12` | **Monthly retention:** Keeps 1 backup per calendar month for up to 12 distinct months. |

## Clean `.env` Configuration

```env
# ── Google OAuth 2.0 Credentials (Required) ─────────────────────────
GOOGLE_DRIVE_CLIENT_ID=your-client-id.apps.googleusercontent.com
GOOGLE_DRIVE_CLIENT_SECRET=your-client-secret
GOOGLE_DRIVE_REFRESH_TOKEN=your-refresh-token

# ── Target Google Drive Folder (Optional) ───────────────────────────
GOOGLE_DRIVE_BACKUP_FOLDER_ID=                   # Leave blank to auto-use "Laravel Backups"
GOOGLE_DRIVE_BACKUP_FOLDER_NAME="Laravel Backups"

# ── Retention Policy Rules (Optional) ───────────────────────────────
GOOGLE_DRIVE_BACKUP_RETENTION_DAILY=30           # Number of daily backups to keep (all intraday for latest day)
GOOGLE_DRIVE_BACKUP_RETENTION_WEEKLY=8           # Number of weekly backups to keep (1 per week)
GOOGLE_DRIVE_BACKUP_RETENTION_MONTHLY=12         # Number of monthly backups to keep (1 per month)

# ── General (Optional) ──────────────────────────────────────────────
GOOGLE_DRIVE_BACKUP_ENABLED=true                 # Set false to disable backups in local/staging
GOOGLE_DRIVE_BACKUP_VERIFY_MODE=metadata         # metadata | checksum | full-download | none
```
